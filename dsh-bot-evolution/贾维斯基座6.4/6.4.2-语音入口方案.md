## 0. 目标与边界

- **目标**：做出「说 → 文本 → 执行 → 语音回」最小闭环，让副驾具备贾维斯特质 #2「听懂会说」（语音 I/O）。
- **本步范围（已用户批准「继续」= 启动 6.4.2 调研）**：调研本地/免费 STT/TTS 方案 + 本机可行性实测 + 写实现方案，**不动外部账号、不接云端 API、不下载超大模型**。
- **待用户点头才动**：AnythingLLM/OpenAI Whisper API、Azure Speech、ElevenLabs、Edge-TTS 等云端方案；需外接账号或网络身份即归入此类，按红线「蓝逐条点头前不 active、不外发」。

| 检查项 | 结果 | 含义 |

| Python | 3.11.9（已装） | 可跑 pip 装 vosk / whisper / piper |
| ffmpeg | yes | 音频格式转换/切片可用 |

## 3. 推荐栈（MVP → 升级）

- **MVP（零安装、立即可验）**：STT=Vosk(small-zh) + TTS=Windows SAPI。
  - 理由：TTS 已零成本可用；STT 仅一次 pip + 模型下载，无账号，最小权限。
- **音质升级（可选，仍离线）**：TTS 换 Piper（中文模型 zh_CN-huayan）。
- **高保真离线（可选）**：STT 换 Whisper.cpp；TTS 换 Coqui。
- **云端（待点头）**：Azure / Whisper API / ElevenLabs / Edge-TTS——任何需账号或云身份的，全部归入「用户点头后再接」。

## 4. 闭环设计（说→文本→执行→语音回）

```
[麦克风] 
  → STT(Vosk/Whisper)        → 文本指令
  → [Bot 推理/执行层]         → 调 desktop-control / 记忆 / 协作
  → 文本结果
  → TTS(SAPI/Piper)           → [扬声器]
```

- **接入点**：封装为共享 capability `voice-io`（五段结构，类似 `desktop-control`）。
- **触发方式**：本地热键 / 唤醒词（Vosk 关键词识别）启动一次听写；或常驻轻量监听（耗资源，待定）。
- **安全**：语音指令走与文字相同的自治策略层（6.4.3 待做）与硬闸门；涉及授权/外部账号/凭据的动作一律「先请示」，不因「听到」就自动执行高危操作。

- 语音指令默认不绕过硬闸门；高危动作仍「先请示」。
- 常驻监听的实时性与 token/算力成本待 6.4.3 自治策略层评估后再定。

## 8. PoC 实测记录（2026-11-10）

> 用户连回「继续」推进。落实 `voice-io-poc.py` 并跑通最小闭环。

### 本机可行性（再确认）
- Python 3.11.9 / ffmpeg yes / 声卡在位（Realtek HD Audio Mic input 等）。
- SAPI 已装 2 枚语音：中文 `Microsoft Huihui (zh-CN)` + 英文 `Microsoft Zira (en-US)`。

### TTS（零安装，✅）
- `python voice-io-poc.py --tts-wav out.wav "..."` 经 SAPI 把中文合成进 WAV（test_tts.wav 223,974 bytes），不发声、不扰人，证明「念回」本地可用。

### STT（离线 Vosk，✅ + 一个关键坑）
- 模型：官方中文小模型 `vosk-model-small-cn-0.22`（44MB，Apache 2.0），从公开 CDN 一次性拉取（无账号）。
  - 首跑误用 `vosk-model-small-zh-0.22` 返回 404，已修正为 `vosk-model-small-cn-0.22`。
  - 下载曾瞬时卡死（urlretrieve 卡 22.6MB / 8h），改用 `curl -C - --retry` 断点续传，~3.5MB/s 拿下剩余 20MB。
- **关键发现（必记）**：Vosk 0.3.45 的 C++ 层用 ANSI 窄字符路径，无法从含中文用户名（`梁泽贤`）的目录加载模型，报 `Failed to create a model`。须把模型放在**纯 ASCII 路径**——已规范到 `C:\vosk-model-small-cn-0.22`（实测 `MODEL_OK`，日志 `Loading HCL and G from .../HCLr.fst .../Gr.fst`）。
- `--stt-check` 列出 10+ 麦克风输入设备（含 Realtek HD Audio Mic input / Mic Array input）。
- `--stt-mic 6` 实时捕获 + 解码跑通无报错（窗口静音则结果为空，属正常）。
- **TTS→STT 自闭环验证**：SAPI 合成中文→ffmpeg 重采样 16k 单声道→Vosk 解码，成功吐出中文文本 token，证明「说→文本」链路通（控制台因 GBK 编码显示乱码，内容为中文音节）。

### 结论
语音入口 MVP（SAPI TTS + Vosk STT）本地零账号跑通；唯一硬约束是**模型必须 ASCII 路径**。下一步封装共享 capability `voice-io` 并挂执行 bot。
