# autonomy-policy：自治策略层

> 来源：贾维斯基座 6.4.3（2026-11-10），实证见 `dsh-bot-evolution/贾维斯基座6.4/6.4.3-自治策略层方案.md`
> 用途：每个任务入口先判"自主干 vs 请示"，留决策日志，安全侧默认请示

## 目标
给执行 bot 一套"该自己动手还是先问用户"的判断框架与决策日志格式。默认安全侧：先扫 ASK（高优先 11 类必须先请示）后扫 AUTONOMY（6 类可自主），否则 ASK。让 bot 主动但不越权。

## 前置条件
- 任务以文本/语音（语音走 voice-io）进入，先做本判定再做动作。
- 已知红线：涉及用户授权/外部账号/凭据/发对外消息/改 state.json（双向匹配 `assistants|ego|state\.json`）/删改用户文件等一律 ASK。
- 日志可追加写文件（如 `autonomy-decision-log.md`）。

## 步骤
1. **进任务**：拿到任务文本。
2. **先扫 ASK（高优先 11 类）**：授权/凭据/token、外部账号、对外发邮件/消息、越界写 `assistants|ego|state\.json`、删除/覆盖用户文件、付费/订阅、不可逆操作、涉及他人隐私、法律/伦理敏感、用户明确"先问"、模糊/信息不足 → 命中即 ASK 并给依据。
3. **再扫 AUTONOMY（6 类）**：纯本地只读查询、本工作区文件读写（非红线）、运行用户已批准的命令、信息整理/总结、在本群/本线授权范围内协作、可逆的小步验证 → 可自主。
4. **默认**：未命中自主 → ASK（安全侧）。
5. **记日志**：每条决策写 时间/任务/判定(ASK|AUTONOMY)/依据/动作，追加到决策日志。
6. **执行或回问**：AUTONOMY 直接干；ASK 回用户并给可选项。

## 常见坑
- 中文自然语序宽容：`截.{0,3}(屏|图)` 命中"截个屏"；越界写双向 `(改|写|删|动).{0,4}(assistants|ego|state\.json)` 覆盖"改 state"与"state 改一下"。
- 语音入口同样走本层：听到高危也先请示，不因"听到"降级。
- 默认安全侧：宁可多问，不替用户做不可逆/授权类动作。
- GBK 乱码：判定/日志统一 UTF-8。
- 命中多个：ASK 优先于 AUTONOMY。

## 验收标准
- [ ] 判定矩阵覆盖 ASK 11 类 + AUTONOMY 6 类 + 默认。
- [ ] PoC 跑通多实例（自主/请示/默认）且日志完整。
- [ ] 越界写 state.json 双向匹配、凭据 token、对外发邮件均正确判 ASK 并给依据。
- [ ] 零凭据明文、assistants/ 零改动、与 1.2 闸门解耦。
