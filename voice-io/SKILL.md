# voice-io：本地/离线语音入口

> 来源：贾维斯基座 6.4.2（2026-11-10），实证见 `dsh-bot-evolution/贾维斯基座6.4/6.4.2-语音入口方案.md`
> 用途：让执行 bot 具备"听（STT）"与"说（TTS）"能力，零外部账号、离线可用

## 目标
把语音输入/输出接入 bot 的文字通道：用户说话 → 转文本 → 走与文字相同的自治策略层（6.4.3）与硬闸门 → 执行 → 结果用语音念回。让 bot 能"听指令、回语音"，离线、零外部账号。

## 前置条件
- Windows + 已装 SAPI 语音（系统自带 Microsoft Huihui(zh-CN) / Microsoft Zira(en-US)，零安装即可 TTS）。
- Python 3.11+；ffmpeg 就绪（音频采集/重采样）。
- 离线 STT 推荐 Vosk（下载 zh 模型到本地，零外部账号）；云端 STT 标"待用户点头才动"。
- 麦克风设备可用；`pyaudio` / `sounddevice` 之一可采集。

## 步骤
1. **采集**：打开麦克风，分帧读 PCM（16k 单声道）。
2. **识别（STT）**：Vosk 流式识别 → 中文文本；静音切句。
3. **入自治层**：文本作为与文字相同的入口，走 6.4.3 自治策略层（自主 vs 请示）与硬闸门；涉及授权/外部账号/凭据一律先请示，不因"听到"就自动执行高危。
4. **执行**：按判定结果执行（自主干或回问用户）。
5. **回念（TTS）**：SAPI 把结果文本念出（选 zh-CN 语音）。
6. **（可选）常驻监听**：实时性/算力成本待 6.4.3 评估后再定，默认按需触发。

## 常见坑
- 麦克风设备索引：多设备时先枚举再选；权限被占（其他程序独占）会打不开。
- Vosk 模型：中文须下 `vosk-model-small-zh-*` 到本地，首次需联网下载但运行离线。
- SAPI 语音缺失：某些环境无 zh-CN 语音，需装语言包或退回英文 Zira。
- 语音 ≠ 免闸门：听到"删掉xx""发邮件"等高危也须走请示，不因语音输入降低安全侧默认。
- GBK 乱码：日志/输出统一 UTF-8。

## 验收标准
- [ ] 说 → 文本 → 执行 → 语音回环在本地跑通（PoC 验证）。
- [ ] 离线可用：无外网也能 STT + TTS（Vosk 本地模型 + SAPI）。
- [ ] 涉及授权/凭据/外部账号的动作触发"先请示"，不因语音自动执行高危。
- [ ] 零外部账号、零凭据明文；与 1.2 闸门解耦。
